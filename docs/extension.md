# 浏览器侧栏安装

Mochi Reader 提供共享同一套界面的网页与 Chrome Manifest V3 扩展。扩展通过本机地址 `http://127.0.0.1:8765` 连接 Python 服务。浏览器需要 Chrome 116 或更高版本；其他 Chromium 浏览器是否提供侧栏接口取决于其自身支持情况。

## 1. 启动本地服务

先按项目 README 安装依赖并启动服务，再访问 `http://127.0.0.1:8765` 确认网页可用。未配置 DeepSeek API key 时，界面会明确显示离线演示模式，采用原文摘录；配置后才会调用真实模型。

可在网页或侧栏的「API 连接设置」填写 API Key、接口 Base URL 和模型，保存后立即生效，不必重启服务。配置发送给本机 Python 服务，默认明文保存为数据库同目录的 `provider-settings.json`（通常为 `data/provider-settings.json`）。浏览器不把密钥缓存到 `localStorage`，配置读取接口也不返回完整密钥；扩展安装包不包含个人配置。

留空密钥会保留已有值；显式清除密钥后回到演示模式。切换服务的域名、协议或端口时需重新输入相应密钥，或显式清除旧密钥。测试连接只请求提供商的 `GET /models`，不生成文字、不发送文章，也不等于真实问答已验证。`.env` 可以提供高级默认值，但网页已保存的设置优先。

兼容服务需支持 Chat Completions SSE；学习卡还需 JSON object 输出模式。接口地址填写服务的基础地址，例如其要求的 `https://…/v1`。部分服务不提供 `/models`，此时连接检查失败不代表问答一定不可用，可手动检查生成。

## 2. 准备扩展

在仓库根目录运行：

```bash
python scripts/package_extension.py
```

脚本把 `web/` 的共享界面复制到 `extension/web/`，生成 `dist/mochi-reader-extension.zip`。如修改了网页界面，需要重新运行脚本，然后在扩展管理页刷新扩展。

## 3. 加载并使用

1. 打开 Chrome 扩展管理页面 `chrome://extensions`，启用右上角的「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择仓库的 **extension** 文件夹。也可以把 ZIP 解压到单独文件夹后选择该文件夹。
3. 打开一篇普通的 HTTP/HTTPS 技术文章，通过工具栏点击 Mochi Reader 图标，打开侧栏。建议把它固定到工具栏。
4. 在侧栏主动选择读取当前页面。只在这一步读取文章文本；网页内容不会自动上传。
5. 导入后进行原文问答、生成知识卡和自测。真实模型模式会把用于回答的检索段落发送给你配置的模型服务。

## 权限与边界

| 权限 | 用途 |
| --- | --- |
| `sidePanel` | 显示阅读侧栏 |
| `activeTab` | 用户点击工具栏后，临时授权当前标签页 |
| `scripting` | 在用户要求导入时提取页面正文 |
| `http://127.0.0.1:8765/*` | 连接自己的本地 Python 服务 |

扩展没有全站长期读取权限，没有远程脚本，也不在浏览器持久保存 API Key。它不能读取 `chrome://` 页面、浏览器商店页面等受保护页面；扫描 PDF、图片文字和登录后的复杂网页也可能提取失败，此时可在网页端手动粘贴文本。页面切换后如授权失效，请再次点击工具栏图标。

## 常见问题

- **侧栏提示无法连接**：保持 Python 服务运行，确认它监听 `127.0.0.1:8765`；HTTPS 或其他端口不在当前扩展的连接权限内。
- **读取失败或正文为空**：切换到普通文章页面，重新点击扩展图标授权，或手动粘贴正文。
- **修改代码后没有变化**：运行打包脚本，在扩展管理页点击刷新，然后重新打开侧栏。
- **仍显示离线演示**：在「API 连接设置」填写并保存 API Key，检查当前模式；保存会立即生效。若使用环境变量，注意已有网页配置优先于 `.env` 默认值。
- **更换服务后无法保存**：切换域名、协议或端口时，输入新服务的 API Key，或显式清除密钥再保存。
